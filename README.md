# @rmdms/viznews

Structural primitives for newsroom data-viz articles. Svelte 5 component library.

Phase 1 (this release): 7 structural primitives (Sticky, ScrollSteps, Crossfade, Grid, Split, Sequence, Lightbox) + core utilities.

Status: `0.1.0-alpha` — internal milestone. Not yet shippable for real articles (content primitives come in phase 2).

## Install

```sh
bun add @rmdms/viznews@alpha
```

## Dev

```sh
bun install
bun run dev
```

See `docs/primitives.md` for per-primitive contracts and invariants.
